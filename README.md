# Little Moon 🌙

A cute, simple period diary made for a teenager. It tracks periods and how she feels, and nothing else.

- Big "My period started today" button and a cycle ring
- Gentle prediction of the next period, shown as a date range
- Log flow, cramps, moods, body symptoms and a little note
- Calendar with period days, expected days and notes
- Averages, past periods and most common feelings
- Reminder banner, plus calendar alerts you can add to the iPad's Calendar
- Backup and restore

No pregnancy or fertility features, no account, no ads, and nothing is sent anywhere:
the diary is saved only on the device.

## Install on iPad
Open the site in **Safari** → **Share** → **Add to Home Screen**. Always open it from the home-screen icon.
